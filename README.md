# Data Structures in C#

This repository contains my practice and implementations of some basic data structures using C#.

I created this project to improve my understanding of data structures and learn how they work internally instead of just using the built-in .NET collections.

## Projects

### 1. Linked List (`CA_LinkedList`)
- Singly Linked List
- Doubly Linked List
- Add and remove elements
- Insert elements at a specific position
- Search for elements
- Reverse the list
- Rotate the list left and right
- Find the middle element
- Implemented `IEnumerable<T>` to support `foreach`

### 2. List (`CA_List`)
- Implemented a dynamic array.
- Add elements
- Insert elements at a specific index
- Remove elements
- Search for elements
- Get the first and last index of an element
- Resize the array when it becomes full
- Trim excess capacity
- Implemented `IEnumerable<T>`

### 3. Queue (`CA_Queue`)
- Implemented a queue using a circular array.
- Enqueue and dequeue elements
- Peek at the front element
- Check if an element exists
- Clear the queue
- Automatically increase capacity when the queue becomes full
- Implemented `IEnumerable<T>`

### 4. Stack (`CA_Stack`)
- Implemented a stack using an array.
- Push and pop elements
- Peek at the top element
- Check if an element exists
- Clear the stack
- Automatically increase capacity when the stack becomes full
- Implemented `IEnumerable<T>`
- Basic calculator that converts infix expressions to postfix and evaluates them

## Technologies Used
- C#
- .NET 10
- Visual Studio
